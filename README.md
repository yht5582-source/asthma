# 氣喘臨床最佳藥物決策推導系統

這是一個以繁體中文呈現的氣喘藥物治療階梯決策輔助工具。專案以單一靜態網頁 `index.html` 實作，依據 GINA 氣喘治療階梯與 Track 1 / Track 2 概念，協助臨床人員依病人症狀、急性發作風險、肺功能與 Type 2 發炎表型，即時推導建議治療階梯與代表性處方方向。

> 本工具用於臨床教育、門診討論與決策輔助，不應取代醫師完整病史詢問、理學檢查、肺功能判讀、吸入器技術確認、共病評估與個別化處方判斷。

## 專案特色

- 純靜態 HTML 單頁工具，無需後端、資料庫或建置流程。
- 支援成人與青少年、6-11 歲學齡兒童的評估入口。
- 依輸入條件即時推導 GINA Step 1 至 Step 5 治療階梯。
- 同頁比較 Track 1: ICS-Formoterol 首選策略與 Track 2: SABA + ICS 替代策略。
- 顯示各階梯的緩解用藥、保養用藥與代表處方範例。
- 內建四組快速載入案例，方便教學、展示與測試。
- Step 5 情境下可依 Type 2 biomarker 提示可能的生物製劑評估方向。
- 支援瀏覽器列印，可匯出成紙本或 PDF。

## 評估輸入項目

工具目前使用下列欄位進行治療階梯推導：

1. 病人年齡分組
2. 評估情境：初診未使用控制藥物或現正接受治療
3. 日間氣喘症狀頻率
4. 夜間甦醒頻率
5. 過去 12 個月急性發作史
6. 肺功能測試：FEV1 % predicted
7. Type 2 發炎相關 biomarker：血中嗜酸性白血球、FeNO、IgE / 過敏表型

## 決策輸出

完成任一輸入調整後，右側結果區會即時更新：

- 建議治療階梯：Step 1 至 Step 5
- 症狀與風險摘要
- 臨床指引概念說明
- Track 1 首選治療建議
- Track 2 替代治療建議
- 代表性吸入藥物與劑量範例
- Step 5 重度難治型氣喘與生物製劑評估提示

## 使用方式

### 直接使用

下載或 clone repository 後，以瀏覽器開啟 `index.html`：

```bash
open index.html
```

也可以直接在檔案總管或 Finder 中雙擊 `index.html`。

### 使用本機靜態伺服器

如果希望用本機網址測試，可在 repository 根目錄啟動簡單的靜態伺服器：

```bash
python3 -m http.server 8000
```

接著開啟：

```text
http://localhost:8000
```

## 技術說明

- 前端：HTML、CSS、Vanilla JavaScript
- 圖示：Font Awesome CDN
- 部署型態：靜態網站
- 建置流程：無
- 套件管理：無

因為所有樣式與互動邏輯都內嵌在 `index.html`，修改後不需要執行 build，只要重新整理瀏覽器即可看到更新。

## 臨床使用注意事項

- 請先確認病人診斷符合氣喘，並排除 COPD、心衰竭、感染、聲帶功能障礙等可能鑑別診斷。
- 實際治療前仍需確認吸入器可近性、病人吸入技巧、用藥順從性、副作用、共病與藥物給付條件。
- Step 5 與生物製劑提示僅作為轉介與進一步評估方向，實際使用需依當地適應症、給付規範與專科判斷。
- 小兒病人需依年齡、體重、可使用劑型與兒科建議調整，不能直接套用成人劑量。
- 急性氣喘發作、低血氧、呼吸窘迫或疑似 impending respiratory failure 時，應依急症流程處置，不應依賴本工具延誤治療。

## 開發與維護

目前專案刻意維持為簡單的靜態網頁，方便在 GitHub Pages、院內靜態網頁空間或本機環境快速部署。若後續要擴充，建議優先考慮：

- 將決策邏輯獨立成可測試的 JavaScript 模組
- 加入 GINA 版本註記與更新日期
- 補充兒童族群專屬的劑量與限制
- 加入處方輸出、列印格式與病歷摘要模板
- 建立臨床規則測試案例，避免更新時造成階梯推導錯誤
